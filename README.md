En main.py se encuentran 3 funciones comentadas, una para los algoritmos de busqueda no informada donde se puede pasar como 
parametro la función BFS o UCS como algoritmo, otra función para las búsquedas informadas donde se pasa como parametro busqueda_Greedy o A_star y por ultimo la funcion para correr el algoritmo genetico. Para el benchmarking se usó benchmarking.py donde se cambiaba el algoritmo a mano.
